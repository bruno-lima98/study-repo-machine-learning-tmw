# Machine Learning Study Repository

This repository contains practical exercises and examples developed while studying Machine Learning.

The projects cover different concepts and models using Python and scikit-learn.

## 🎯​ Purpose

The main goal of this repository is to practice Machine Learning concepts through simple and practical examples.

## 📚 Topics Covered

- Decision Trees
- Linear Regression
- Logistic Regression
- Naive Bayes
- Classification
- Model Predictions and Probabilities
- Classification Metrics
- ROC Curve and AUC
- Basic Machine Learning Applications
- Streamlit

## 📁 Structure

| File | Description |
| --- | --- |
| `01_beer_case.py` | Decision Tree classification using beer characteristics |
| `02_star_wars_case.py` | Decision Tree classification using a Star Wars dataset |
| `03_beer_grade_case.py` | Linear Regression and Decision Tree Regression |
| `04_classification.py` | Classification using Logistic Regression, Decision Tree and Naive Bayes |
| `05_metrics.py` | Classification metrics, ROC Curve and AUC comparison |
| `06_app_hapiness.py` | Streamlit application using a trained classification model |

## 🛠️ Tech Stack

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Streamlit
